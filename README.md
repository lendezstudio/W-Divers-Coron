# W Divers Coron website

A static, multilingual (English and Korean) website, generated by a small Python build script.

## Build

Requirements: Python 3.12+ and Pillow (`pip install pillow`). ffmpeg is optional and is only used once to make the video poster.

```
python src/build.py
```

The output goes to `dist/`. Deploy that folder as the web root on any static host. Image derivatives are cached, so later builds are fast.

### GitHub Pages

The site is served from https://lendezstudio.github.io/W-Divers-Coron/, which is why `BASE_PATH` in `src/config.py` is `/W-Divers-Coron`. Set it to `""` when the site moves to its own domain.

`.github/workflows/pages.yml` publishes the committed `dist/` folder on every push to `main` or `website-build`. One-time setup: **Settings > Pages > Build and deployment > Source: GitHub Actions**. Always rebuild before committing.

Preview locally:

```
cd dist
python -m http.server 8000
```

With `BASE_PATH` set, preview from a parent folder that contains a `W-Divers-Coron` copy of `dist`, or build with `BASE_PATH = ""` and open http://localhost:8000/. Open pages through a server, not by double-clicking the files.

## Where things live

| Path | Contents |
|---|---|
| `src/config.py` | Contacts, KakaoTalk IDs, address, locales, `SITE_URL` |
| `src/content/en.py`, `src/content/ko.py` | All page copy, per language, with matching keys |
| `src/data.py` | Course catalogue (empty until offerings are verified) and dive-site editorial sources |
| `src/media.py` | Image manifest (provenance, alt text in both languages, crop focus, gallery categories) and image processing |
| `src/build.py` | Templates, components and page renderers |
| `src/static/` | CSS, JavaScript and self-hosted fonts (Outfit, Inter, OFL licence) |
| `docs/reference-analysis.md` | Design reference: observed vs adapted vs not shown |
| `docs/owner-confirmation.md` | Facts still to confirm, unused media and content decisions |

## Common edits

- **Change copy:** edit the matching key in both `src/content/en.py` and `src/content/ko.py`, then rebuild.
- **Add a dive site:** add an entry to `SITES` in both content files, plus its sources in `SITE_META` (`src/data.py`).
- **Publish a course:** add a verified entry to `COURSES` in `src/data.py`. The schema is documented there.
- **Add a language:** copy `src/content/en.py` to `src/content/<code>.py`, translate it, and add the code to `LOCALES`. The root redirect in `render_root()` currently handles `en` and `ko`.
- **Go live on a domain:** set `SITE_URL`. That enables canonical URLs, hreflang alternates, og:url and `sitemap.xml`.

## Inquiry handling

There is no form backend. The contact page builds a message in the browser, and the visitor chooses to continue in WhatsApp, prepare an email, or copy the text (for KakaoTalk or anything else). Nothing is stored or sent by the site. If a backend is added later, update the privacy page to match.
